# ЙОМ — исключительно общественное мнение

Работающий MVP социальной ленты: React JS + Vite, Node.js + Express, PostgreSQL.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://localhost:3000. Без настройки сервера БД используется PGlite — PostgreSQL в WebAssembly, данные сохраняются в `.data/`. Это локальный режим для одного процесса. Создайте аккаунт через интерфейс. Начальные посты — вымышленные примеры. Демо-вход: `anya` / `iom-demo-2026`.

## Отдельный PostgreSQL

```sh
docker compose up -d
DATABASE_URL=postgres://iom:iom_local_password@localhost:5432/iom npm run dev
```

Схема создаётся при старте. Данные локального режима автоматически не переносятся. `.env.example` служит образцом; переменные передаются через окружение (файл `.env` автоматически не загружается).

## Проверки и production-сборка

```sh
npm test
npm run build
npm start
```

Для HTTPS задайте `COOKIE_SECURE=true`. При публичном запуске замените демонстрационные пароли и добавьте модерацию, восстановление пароля и инфраструктурное ограничение запросов. Это MVP: изображения, подписки, уведомления и модераторская панель пока не реализованы. Лента ограничена последними 100 записями.

## Возможности

- Регистрация, вход и выход; хеширование паролей, серверные сессии с HttpOnly cookies.
- Публикации до 1000 символов, пять тем, поиск по тексту и имени.
- Сортировка по времени или лайкам; комментарии, лайки, закладки.
- Свои публикации в профиле, удаление только автором.
- Копирование публикации, адаптивный интерфейс и состояния ошибок.

`npm test` поднимает отдельный сервер и временную БД; проверяет регистрацию, сессию, публикацию, идемпотентные лайки, сохранение, комментарии, валидацию и права удаления. Подключение к внешнему PostgreSQL нужно проверять отдельно в окружении с PostgreSQL.
